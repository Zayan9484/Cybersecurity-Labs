# OSINT Methodology

The reconnaissance portion of the lab used public sources and security-research tools to compare information about a selected organization and its public web presence.

The workflow included:
1. identifying the primary domain;
2. reviewing public hosting/domain information;
3. identifying visible web technologies;
4. checking public certificate/subdomain sources;
5. comparing subdomain results from multiple tools; and
6. validating which discovered hosts responded over HTTP/HTTPS.

The exercise was intended to practice information collection and cross-checking, not exploitation.
